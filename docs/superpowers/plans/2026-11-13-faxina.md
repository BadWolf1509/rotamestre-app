# Faxina do repositório e do código — plano de execução

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** repositório navegável (PR 1) e código sem exports mortos, sem `as any` evitável e sem a vitrine pública (PR 2).

**Architecture:** duas entregas em sequência, sem empilhar. PR 1 só move/apaga docs e arquivos soltos e limpa branches. PR 2 remove o que o knip acusa, tipa 6 casts e põe uma guarda de build na rota `/design-system`.

**Tech Stack:** git/gh, knip 6, TypeScript, Jest (jest-expo), Expo Router, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-13-faxina-design.md`

## Global Constraints

- Tudo em PT-BR (commits, PRs, comentários).
- Merge: squash + `gh pr merge --admin`, com pending = 0 logo antes; nunca empilhar PR.
- Branch antes da 1ª edição; `git pull --ff-only`; se o pre-commit reformatar, commit `style:` separado.
- Commits terminam com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; PRs com `🤖 Generated with [Claude Code](https://claude.com/claude-code)`.
- Lint do repo inteiro: `npm run lint` (não só `app src`).
- Variantes de plataforma (`*.web.tsx`, `*.native.tsx`) não são apagadas por parecerem mortas.
- Texto com crase não passa por `node -e` nem por string de shell: use Write/Edit ou heredoc `'EOF'`.

## Review Focus

1. **Barrel usado por string de mock:** `jest.mock('@/components/drawer', () => ({ DrawerHeader: … }))` não é import, e o knip não o vê. Antes de tirar uma linha de barrel, `git grep -n "<caminho do barrel>"` em `**/__tests__/**` e `jest.mocks/`; o jest completo é a prova (Task 5, passo 3).
2. **Export exigido por declaração de tipo do Unistyles:** os temas de `src/unistyles.ts` podem existir para `declare module 'react-native-unistyles'`/`StyleSheet.configure`. Se o `export` sumir e o `tsc` continuar verde, ele não era necessário; se o tsc acusar, mantenha e registre no `knip.jsonc` com comentário (Task 6).
3. **Flag da vitrine ligada em produção sem querer:** a Vercel ou um `.env` local com `EXPO_PUBLIC_VITRINE_DS=1` reabriria a rota. Confira `vercel env ls` (ou MCP da Vercel) e o `.env.example` (Task 9, passo 6).
4. **Doc movido ainda citado por agente/skill/memória:** `.claude/` (agents, skills, refs) e a memória do usuário citam caminhos de `docs/`. O grep de links quebrados inclui `.claude/` (Task 2, passo 4).
5. **Branch remoto com PR reaberto ou Dependabot novo entre a listagem e a deleção:** reconfira o estado na hora de apagar (Task 1, passo 2).

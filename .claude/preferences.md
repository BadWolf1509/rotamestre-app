# Preferências do Projeto

## Comunicação

- ❌ **Não criar arquivos .md para cada interação**
- ✅ Respostas diretas e objetivas
- ✅ Criar documentação apenas quando essencial (bugs críticos, configurações complexas)
- ✅ Usar markdown no chat quando necessário

## Quando criar documentação:

- Correções importantes de bugs (ex: ANDROID_BUILD_FIX.md)
- Configurações complexas que precisam ser referenciadas depois
- Guias de deploy ou setup críticos

## Quando NÃO criar:

- Explicações de conceitos
- Análises temporárias
- Instruções simples
- Respostas a perguntas pontuais
